AI Daily UI / UX 参考

视觉方向保持“手绘日报 / 草稿本”：暖纸色、墨色边框、手写感标题、喷漆状态标签。实际页面在 app/templates/index.html、app/static/style.css 和 app/static/app.js。

保留的页面结构

左栏日期日历、抓取、五段时间线、字数限制
主栏标题、作者、正文/封面切换、状态栏、定时、复制、发布
状态IDLE、RUNNING、READY、DONE、FAILED

当前交互

选择日期 → POST /api/runs → 轮询 GET /api/runs/<id> → 用持久化事件更新时间线 → ready 后显示正文与封面 → 可复制或创建微信草稿。

页面不再使用 SSE、/api/fetch 或全局文章变量。模型与抓取内容均用 DOM 节点的 textContent 渲染。

定时交互

点击时间旁的“保存”调用 POST /api/schedule。成功才显示“每日定时任务已更新”；它不是只保存一个页面字段。

关键文案

  • 生成完成：文章已生成，尚未发布
  • 发布完成：微信草稿已创建
  • 失败：显示安全错误摘要并允许重试
