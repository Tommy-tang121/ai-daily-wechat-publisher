3. 组件与状态

组件默认状态交互 / 其他状态
日历显示当前月，今天有浅色底，未选择日期时自动选中今天。左右箭头切月；选择日期后日期变深色并更新标题为“AI 行业热点新闻 | 日期”。
抓取按钮纸张底、墨色边、旋转箭头图标。悬停上移 2px、阴影加深；运行中禁用并降至 40% 不透明度。
五段时间线抓取、重写、排版、封面、完成均显示“等待中”。进行中：橙色圆点呼吸；完成：绿色勾选并弹跳；失败：红色叉和摇晃。步骤由后端事件驱动。
错误卡片隐藏。运行失败后显示 FAILED、红色满进度条和安全错误摘要。
标题 / 作者 / 字数标题和作者是单行输入；字数为 50–500 的数字框。字段失焦变更时立即保存到本地 SQLite；焦点边线变橙色。
正文 / 封面预览正文标签激活，未生成时显示“请先选择日期并点击抓取”。正文按“今日观察 → 分类 → 标题 / 正文 / 来源链接 → 小编短评”渲染；封面标签展示当前运行的 900×500 图片。
编辑点评正文中没有数据时不显示。今日观察和小编短评均用浅橙背景、橙色左边线、手写栏目名。
复制 / 发布复制始终可点；发布在文章 ready 前禁用。复制写入浏览器剪贴板；发布成功后清空本地预览和运行标记，避免保留日报历史。
定时保存时间输入框加“保存”按钮。保存调用 Windows 计划任务接口；成功 / 失败均以右下角 Toast 提示。

运行状态徽章

IDLE 等待操作　RUNNING... 抓取、重写或清理中　READY 可预览和发布　DONE 草稿已创建　FAIL 生成失败　CHECK 发布结果待人工确认。

4. 页面状态流转

选择日期 → 保存标题、作者、字数 → POST /api/runs → queued / scraping / rewriting → 每秒轮询 GET /api/runs/<id> → ready（展示正文和封面） → 用户发布 → publishing → finalizing → 清除本地内容并回到空白页面。

失败路径：内容阶段失败 → failed → 可重新抓取。微信调用结果不确定 → publication_uncertain → 用户先核对微信草稿箱，再在确认提示中重新生成。
抓取：开始、完成
重写：一次改写当天全部资讯并返回完整文章
排版：确定性 Markdown 组装完成
封面：生成 900×500 本地临时封面
完成：文章已生成，尚未发布
错误：失败步骤显示后端错误摘要

5. 事件绑定与接口

页面元素事件实际行为
日历前后箭头click仅改变显示月份，不请求后端。
某个日期click选中日期、更新日报标题、保存标题设置。
标题 / 作者 / 字数changePOST /api/config 保存设置。
抓取clickPOST /api/runs，随后每 1000ms 轮询运行记录。遇到待确认状态，先弹出浏览器确认框。
正文 / 封面标签click切换预览区域，不重新生成内容。
复制click复制当前正文预览的纯文本到剪贴板。
发布clickPOST /api/runs/<id>/publish；仅 ready 状态可用。
定时保存clickPOST /api/schedule 更新唯一 Windows 任务 AI Daily Publisher。

页面不使用 SSE；使用 HTTP 轮询和持久化事件。浏览器把当前 run_id 放在 localStorage，刷新后尝试恢复；已清理或已发布的运行返回 404 时会自动清空页面。
