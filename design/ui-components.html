SSE 协议

属性值
端点GET /api/progress
MIMEtext/event-stream
事件名stage
数据格式{"stage": str, "status": str, "message": str, "percent": int}
连接方式JavaScript new EventSource('/api/progress')
重连策略EventSource 自动重连；前端手动 close() 在 done/error 时关闭；onerror 回调处理连接中断

正常序列：

event: stage
data: {"stage":"scraping","status":"complete","message":"抓取完成 (22条)","percent":25}

event: stage
data: {"stage":"rewriting","status":"progress","message":"重写中 (3/22)...","percent":29}

event: stage
data: {"stage":"rewriting","status":"complete","message":"重写完成","percent":50}

event: stage
data: {"stage":"formatting","status":"complete","message":"排版完成","percent":75}

event: stage
data: {"stage":"done","status":"complete","message":"全部完成","percent":100}

异常序列：

event: stage
data: {"stage":"error","status":"error","message":"API 调用失败: Connection refused","percent":0}

后端实现（main.py:36-79）：

1. POST /api/fetch 存入 app.config["CURRENT_DATE"] 和 CURRENT_MAX_WORDS，清空 CURRENT_ARTICLE
2. GET /api/progress 启动 daemon=True 后台线程执行 run_pipeline()
3. 通过 queue.Queue 传递 (type, payload) 给 SSE generator
4. type == "stage" → yield SSE event。type == "result" → 存入 CURRENT_ARTICLE + yield done 后 return
5. type == "error" → yield error 后 return。queue.Empty 每 0.5s 重试保持连接

Timeline 状态机

初始: 全部 idle (等待中)

点击抓取 → scraping:active (准备中...)

scraping:complete event
  → scraping:done ✓
  → rewriting:active (重写中...)

rewriting:progress event (每 n/总 触发)
  → rewriting:active (重写中 n/总...)
  → 进度条更新

rewriting:complete event
  → rewriting:done ✓
  → formatting:active (排版中...)

formatting:complete event
  → formatting:done ✓
  → cover:active (生成中...)

done event (含 cover)
  → cover:done ✓
  → done:done ✓
  → 全部完成

error event (任意步骤)
  → 找到当前的 active step → 设为 fail (红色 ✕ shake)
  → 所有后续步骤保持 idle
