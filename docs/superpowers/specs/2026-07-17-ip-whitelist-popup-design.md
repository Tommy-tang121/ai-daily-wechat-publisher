# 定时发布失败时显示 IP 白名单原因

**日期：** 2026-07-17
**状态：** 已确认，待实施

## 要解决的问题

微信草稿发布被 IP 白名单拒绝时，系统原先把真实错误统一替换成“发布结果待确认”。用户无法知道应把哪个出口 IP 加入微信公众平台白名单，只能人工排查。

## 根本原因

发布器已经收到微信 `40164 invalid ip` 的响应，其中包含本次请求实际使用的公网出口 IP；但工作流没有保留该安全错误，定时任务又再次用通用文字覆盖了它。

## 已确认方案

1. 只在微信返回 `40164 invalid ip` 时，从返回文字中取出本次请求的出口 IP。
2. 将其转换成明确提示：把该 IP 加入微信公众平台的 IP 白名单后重试。
3. 其他发布异常保留原始但已脱敏的原因，最多 300 个字符。
4. 定时任务直接使用工作流已保存的失败原因，Windows 弹窗自然展示该原因。
5. 不增加额外的“查 IP”网络请求；微信失败响应里的 IP 才是实际被拒绝的出口 IP。

## 安全边界

- 不保存或显示 API Key、微信公众号 AppID、AppSecret。
- 不尝试读取微信公众平台完整白名单：微信 API 不提供这个能力。
- 不改变首次加一次重试的定时任务规则。

## 验收标准

- `40164 invalid ip 138.199.22.133` 会显示“当前出口 IP：138.199.22.133”。
- 弹窗和任务失败信息保留该提示。
- 配置中的密钥仍会被替换为 `***`。
- 原有全部测试与新增测试通过。
