# AI 日报公众号发布助手 PRD

> 当前文档同步日期：2026-07-22。

## 产品目标

每天把 AIHot 当日可用资讯完整改写为可审阅的日报，生成封面，并按用户确认创建微信公众号草稿。用户不需要写代码。

## 核心原则

1. 完整：当天所有具备来源链接的资讯都纳入，不以固定 10 条或 25 条截断；模型返回条目数必须与抓取数相同。
2. 可追溯：每条改写内容都保留原始来源链接。
3. 不误发：生成、预览和复制不等于发布；只有微信返回草稿回执才标记已发布。
4. 可恢复：浏览器刷新、模型短暂失败或计划任务重试不会重复生成或重复建草稿。

## 用户流程

```text
选择日期
  -> 一次模型调用：生成今日观察、全部改写资讯和小编短评
  -> 查看真实进度
  -> 正文 / 封面预览
  -> 复制或确认发布
  -> 微信草稿回执
```

自动定时流程最多执行两次完整处理。第一次遇到 AIHot 连接或 DNS 解析失败时等待 60 秒再重试，避免把两次机会耗在同一段短时网络故障里；两次仍失败才显示 Windows 失败弹窗。

## 页面功能

| 区域 | 行为 |
| --- | --- |
| 日历 | 选择生成日期 |
| 抓取按钮 | 创建或恢复该日期的唯一运行记录；一次提交当天全部资讯，少返回任一条即失败 |
| 时间线 | 显示抓取、改写、排版、封面和完成状态 |
| 正文预览 | 按分类展示改写文章及来源链接 |
| 封面预览 | 显示与当前运行绑定的 900×500 封面 |
| 标题、作者、字数 | 保存到本地 SQLite 设置 |
| 定时保存 | 更新唯一的 Windows 每日计划任务；资讯源连接失败时按“首次失败 → 等待 60 秒 → 第二次尝试”运行 |
| 发布 | 仅在文章 ready 后创建微信公众号草稿 |

## 状态文案

- `处理中`：任务在抓取或改写，页面可以刷新。
- `文章已生成，尚未发布`：可安全审阅、复制或发布。
- `微信草稿已创建`：有可追溯的草稿回执，不再重复创建。
- `运行失败`：显示安全的错误摘要；可显式重试。
- `资讯源域名解析失败`：提示检查网络、VPN 或 DNS，不显示技术堆栈或敏感配置。

## 边界

- 不提供云服务器，也不承诺电脑关机时继续执行。
- 微信 IP 白名单由用户每天手动更新。
- 自动任务在当前 Windows 用户登录且电脑开机时运行。
- 自动任务总共只有首次和重试一次；60 秒等待不会增加第三次尝试。
- 系统创建的是微信草稿，不会自动群发。
